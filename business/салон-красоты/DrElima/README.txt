САЙТ «КОД РОСКОШИ» — Dr. Elima
================================

Это готовый статический сайт (HTML/CSS/JavaScript + изображения).
Ему НЕ нужны база данных, PHP или сервер — он работает на любом хостинге.
Домен: dr-elima.ru


КАК ОПУБЛИКОВАТЬ НА BEGET
-------------------------

1. Войдите в панель Beget: https://cp.beget.com

2. Убедитесь, что домен dr-elima.ru добавлен:
   раздел «Домены» → он должен быть в списке «Мои домены».

3. Откройте «Файловый менеджер» (или подключитесь по FTP).
   Найдите папку вашего сайта — обычно:
   /home/ЛОГИН/dr-elima.ru/public_html/
   (на Beget папка сайта называется по имени домена, внутри — public_html)

4. Загрузите ВСЁ содержимое этого архива в папку public_html:
   - index.html
   - privacy.html
   - style.css
   - script.js
   - robots.txt
   - sitemap.xml
   - папку img (целиком, со всеми вложенными папками)

   ВАЖНО: файл index.html должен лежать прямо в public_html,
   а не во вложенной папке.

5. Откройте https://dr-elima.ru — сайт должен заработать.


SSL-СЕРТИФИКАТ (HTTPS) — ОБЯЗАТЕЛЬНО
------------------------------------
Сайт рассчитан на работу по https. В панели Beget включите бесплатный
SSL-сертификат Let's Encrypt для домена dr-elima.ru:
раздел «Домены» → SSL → выпустить для dr-elima.ru.
После этого сайт будет открываться по защищённому https://dr-elima.ru


ЧТО НАСТРОЕНО НА САЙТЕ
---------------------
- Запись на приём: форма открывает WhatsApp / есть кнопки WhatsApp и Telegram
- При выборе процедуры автоматически подставляется нужный врач
- Адаптив под телефон, планшет и десктоп
- SEO: robots.txt, sitemap.xml, разметка для Яндекса и Google

Если потребуется что-то изменить (тексты, цены, фото) — правки вносятся
в файлы index.html (содержимое) и style.css (оформление).
