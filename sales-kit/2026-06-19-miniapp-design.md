# Дизайн: KARINA Media Telegram Mini App

> Спека от 2026-06-19. Брейншторм Jarvis с Еркином (визуальный компаньон). Концепция A+C, лёгкий MVP, подход C (внутри bot-vercel).

## Цель

Заменить чат-воронку @karina_media_bot на полноценный Telegram Mini App, который САМ демонстрирует продукт. Когда Еркин показывает услугу предпринимателю, тот открывает мини-апп, проходит все этапы и примеряет «как это будет у меня» → оставляет заявку. Цель — выше конверсия и солиднее подача под кассовый спринт.

## Концепция (A+C гибрид)

Зритель проходит 3 экрана:
1. **Шоурум ниш** — сетка плиток (бьюти / магазин / услуги / обучение) на luxury-фото. Тап по нише открывает РЕАЛЬНЫЙ демо клиента (живьём щупает). Сверху/снизу CTA «Хочу себе такой».
2. **«Твой будущий мини-апп»** — один универсальный интерактивный шаблон бизнеса (каталог товаров/услуг + блок записи). Листает как свой. Липкая кнопка «Сделать такой мне».
3. **Заявка** — имя и `@username` подтягиваются автоматически из Telegram; телефон/WhatsApp — в один тап по кнопке «Подтянуть телефон» (`requestContact`); ниша предзаполняется, если пришёл из ниши → отправка.

## Архитектура (подход C — внутри bot-vercel)

- Мини-апп = статическая страница в `bot-vercel/public/app/` (index.html + styles.css + app.js). Открывается через Telegram WebApp SDK.
- **Точка входа:** меню-кнопка бота (`setChatMenuButton` → web_app, URL `https://bot-vercel-five.vercel.app/app/`) + инлайн-кнопка «🚀 Открыть мини-апп» в `/start` (текстом, без эмодзи в финале — единый стиль).
- **Заявка:** мини-апп POST'ит на новый endpoint `bot-vercel/api/lead.js` с телом (name, phone, niche) + Telegram `initData`.
- **Бэкенд `api/lead.js`:** валидирует подпись `initData` (HMAC-SHA256 по bot token — анти-спам), достаёт tg_user/tg_id, пишет в Supabase `bot_leads` (type `miniapp`), шлёт уведомление в группу OWNER_CHAT_ID через Bot API (та же логика 🔥-приоритета).
- **Чат-воронка НЕ удаляется** — остаётся как fallback. Тот же Supabase, та же группа — метрики целы.

## Дизайн / эстетика

- Премиум: фиолетовый градиент KARINA (`#6d5efc → #9b5cf0`), чистые карточки на светлом фоне (`#f5f6fb`).
- **Плитки ниш и карточки товаров — на luxury-стоковых фото** с тёмным градиентом-оверлеем и белым текстом. НЕ эмодзи, НЕ иконки (по требованию Еркина — удешевляют).
- Фото: curated Unsplash/Pexels (free-лицензия), оптимизированные (webp, ~240×160 для плиток), лежат в `bot-vercel/public/app/img/`. Подобрать под ниши: бьюти/спа, бутик/мода, фотостудия, образование.
- Кнопки действий — чистые, текстовые, на градиенте. Telegram WebApp `MainButton`/`BackButton` для навигации где уместно.
- Адаптив под мобильный (мини-апп открывается в Telegram на телефоне).

## Экраны и данные (лёгкий MVP)

- **Шоурум:** 4-5 ниш, у каждой реальная демо-ссылка (drelima-miniapp, mobilograf, plix-miniapp, agenio miniapp, nura/glowseoul). Открывать через `Telegram.WebApp.openLink` или `openTelegramLink`.
- **Шаблон «твой мини-апп»:** ОДИН универсальный (каталог 2 колонки + мок «записаться»). Запись — демонстрационная (не реальное бронирование). Назначение — примерка, не функционал.
- **Заявка:** поля name, phone, niche.
  - **Авто-подстановка из Telegram (без спроса):** `first_name`/`last_name` и `@username` из `initData` → предзаполняют имя и контакт.
  - **Телефон/WhatsApp:** кнопка «Подтянуть телефон» → `Telegram.WebApp.requestContact()` (Bot API 6.9+): пользователь подтверждает «Поделиться» одним тапом → поле заполняется автоматически. Fallback — ручной ввод.
  - **niche** предзаполнен, если перешёл из плитки/демо.
  - **Честное ограничение:** Telegram НЕ отдаёт телефон молча и не даёт «другие контакты» через WebApp — приватность. Максимум авто = имя+username; телефон = один тап-согласие.
  - Submit → `api/lead` (в теле: name, phone, niche + `initData`).

## Критерий успеха

- Мини-апп открывается из бота, проходит 3 экрана на телефоне без багов.
- Заявка из мини-аппа падает в группу «Заявки KARINA Media» и в Supabase `bot_leads` (type `miniapp`), как сейчас из чата.
- Выглядит премиально (luxury-фото, без эмодзи/иконок).

## Вне области (YAGNI)

- Отдельный кастомный шаблон под каждую нишу (сейчас 1 универсальный).
- Реальное бронирование/оплата внутри мини-аппа (только демонстрация + заявка).
- AI-ассистент (отдельный будущий цикл).
- Удаление чат-воронки (остаётся fallback).
