# KARINA Media — бот-воронка

Telegram-бот для приёма заявок на digital-услуги. Человек из WhatsApp-чата переходит в бота → смотрит демо, портфолио, цены → оставляет заявку → она падает вам в Telegram.

## Что умеет

- 🎬 Демо мини-аппов — открываются прямо в Telegram (бьюти, фотограф, магазин)
- 💼 Портфолио и 💰 Цены — готовые сообщения
- 📝 Заявка — собирает нишу, имя, телефон
- 📞 Запись на созвон — имя, телефон, удобное время
- Все заявки приходят вам в Telegram + сохраняются в `leads.json`

## Запуск за 4 шага

### 1. Создать бота
В Telegram напишите **@BotFather** → команда `/newbot` → задайте имя и username. Он пришлёт **токен** (вида `123456:ABC...`).

### 2. Узнать свой chat_id
Напишите боту **@userinfobot** — он пришлёт ваш `id` (число). Сюда будут падать заявки.

### 3. Настроить
```bash
cp .env.example .env
```
Откройте `.env` и впишите `BOT_TOKEN` и `OWNER_CHAT_ID`.

### 4. Установить и запустить
```bash
npm install
npm start
```
Бот запустится. Напишите ему `/start` в Telegram — увидите меню.

## Где разместить, чтобы работал 24/7

Бот работает по long-polling — подойдёт любой из вариантов:
- **VPS** (где живёт Jarvis) — `npm start` под pm2/systemd
- **Railway / Render** — деплой из репозитория, команда запуска `npm start`
- Для теста — просто на вашем компьютере (пока окно открыто)

## Настройка под себя

- Демо-ссылки и тексты (приветствие, цены, портфолио) — вверху `bot.js`, легко править
- `/id` — команда покажет chat_id любого, кто напишет (удобно для проверки)
