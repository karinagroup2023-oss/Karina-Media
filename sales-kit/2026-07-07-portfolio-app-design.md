# Портфолио-апп KARINA Media с админкой — спека (утверждена 07.07.2026)

Визитка + портфолио с детальными кейсами и self-service админкой. Двойная роль: наш канал продаж и живой прототип VIP-админки из линейки v2 (демо на созвонах, шаблон для клонирования клиентам).

## Архитектура

- `Karina-Media/sales-kit/portfolio-app` — React + Vite (JS), react-router, @supabase/supabase-js. Стиль — тёмная гамма KARINA (как price.html).
- БД: существующий Supabase-проект (где таблицы бота), префикс `pf_`. Вынос в отдельный проект — позже, вместе с ботом.
- Деплой: новый Vercel-проект (team karinagroup2023-6262). Старый karina-portfolio и его URL не трогаем; после приёмки Еркином переключаем меню-кнопку бота.
- Стартовые скрины кейсов — из `public/screens/` (копия существующих); новые кейсы — загрузка в Storage bucket `pf-screens` из админки.

## Данные

- `pf_cases`: slug, title, niche, type (miniapp|site|quiz|bot), short_desc, tags[], cover_url, screens[], task_md, solution_md, result_md, live_url, is_concept, published, sort_order.
- `pf_leads`: name, phone, message, case_slug, ref_code, status (new|work|closed).
- `pf_ref_links`: code, label.
- `pf_visits`: ref_code, case_slug (null = главная).
- `pf_admins`: email — список допущенных в админку; RLS-политики через него.
- RLS: anon читает только published кейсы, пишет leads/visits; всё остальное — только email из pf_admins (Supabase Auth, email+пароль).

## Публичная часть

- `/` — визитка (кто мы, цифры, ТОО), видео + было-стало, сетка кейсов из БД с фильтром по типу, CTA «Хочу так же».
- `/case/:slug` — ниша, задача→решение→результат, горизонтальные скрины, live-ссылка, CTA с подстановкой кейса.
- Форма лида: имя + телефон (+7 по умолчанию) + комментарий → insert в pf_leads + уведомление в TG-группу «Заявки KARINA Media» через новый endpoint `api/portfolio-lead` в существующем bot-vercel (токен уже там). После отправки — кнопка «продолжить в WhatsApp».
- `?ref=код` → localStorage → пишется в visits и в лид.
- Честность: NURA, Velvet (+ Mobilograf, StudyMe до подтверждения Еркином) — `is_concept=true`, на странице пометка «Концепт под нишу», без выдуманных результатов. Реальные: DrElima ×3, Agenio, Сымбат, Plix, GlowSeoul.

## Админка `/admin` (SPA с вкладками)

Панель (просмотры, топ кейсов, заявки за период) · Кейсы (CRUD, скрины, скрыть/показать, порядок) · Заявки (статусы, реф/кейс) · Реф-ссылки (код → готовая ссылка, счётчики переходов и лидов).

## Этапы

1. БД + сид 11 кейсов + каркас → публичная часть на реальных данных ✅ проверка: страницы открываются, кейсы из БД
2. Лиды + реф + TG-уведомление ✅ проверка: тестовая заявка доходит в группу
3. Админка ✅ проверка: вход, правка кейса видна на сайте
4. QA (десктоп/390px/TG-webview) → деплой → приёмка Еркина → переключение бота
