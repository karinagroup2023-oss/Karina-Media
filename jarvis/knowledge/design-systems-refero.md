# Refero Styles — банк дизайн-систем для вёрстки

> Когда читать: перед дизайном/вёрсткой любого сайта или мини-аппа KARINA Media (для Армана / karina-ux-dev и при работе через скилл frontend-design).

## Что это
Библиотека **DESIGN.md** — машиночитаемых дизайн-систем с 2000+ реальных продуктов (Apple, Linear, Stripe, Superhuman, Raycast, Cursor, ElevenLabs и т.д.), сделанных под AI-кодеров (Claude Code в их списке). В каждом DESIGN.md: палитра (hex), шрифтовая шкала и семейства, отступы/ритм, компоненты, плюс «общее ощущение» стиля.

- Витрина стилей: https://styles.refero.design/
- Основной сайт / аккаунт: https://refero.design/
- MCP-интеграция: https://refero.design/mcp

## Как пользоваться (базово)
1. Открыть стиль на styles.refero.design под нишу клиента.
2. Скопировать его DESIGN.md.
3. Вставить в контекст Claude Code → верстать в этом стиле (лечит «generic AI look»).

## Доступ и цена (на 2026-06)
- **Free** — открыт лишь маленький кусок библиотеки (несколько %).
- **Pro — $8/мес при годовой оплате** ($14 помесячно): вся библиотека + продвинутый поиск.
- **Team — $10/мес за место** (годовая): общие закладки, совместный доступ.
- **Trial — 3 дня, полный доступ, без карты.** Через 3 дня без оплаты доступ схлопывается до Free, списания нет.
- Enterprise — по запросу: support@refero.design.

## Процесс внедрения в KARINA Media
1. Включить триал → на текущем проекте вытащить 1-2 DESIGN.md под нишу, сверстать кусок, сравнить с обычным результатом.
2. Если разница ощутима — оформить Pro, складывать лучшие системы в `knowledge/design-systems/`.
3. Проверить MCP в Claude Code — автоматизирует подачу стиля без копипаста (вероятно требует Pro).
