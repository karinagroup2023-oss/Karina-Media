# Команда AI-субагентов KARINA Media

Субагенты Claude Code, сконвертированные из профилей `karina-hq/ai-team/`. Подхватываются автоматически при запуске Jarvis. Профили в `karina-hq/ai-team/` — источник истины (правишь роль → обновляй и профиль, и субагента).

## Состав (15 ролей)

### Управление
- `karina-ceo` — Алина, CEO (стратегия, решения, приоритеты)
- `karina-pm` — Дмитрий, Project Manager (планирование, раздача задач)
- `karina-qa` — Диана, QA (финальная проверка перед запуском)

### Создание сайтов
- `karina-research` — Ренат, Web-Парсер (анализ конкурентов)
- `karina-seo` — Николай, SEO (семантика, структура)
- `karina-copywriter` — Айгерим, копирайтер (тексты RU/KZ)
- `karina-ux-dev` — Арман, UX/разработчик (дизайн + вёрстка)

### Маркетинг и рост
- `karina-marketing` — Мария, маркетолог (стратегия, реклама)
- `karina-smm` — София, SMM (соцсети, контент-планы)

### Аналитика и продажи
- `karina-analytics` — Тимур, аналитик данных
- `karina-sales` — Анель, Sales-менеджер (лиды, КП)

### Поддержка бизнеса
- `karina-finance` — Игорь, финансист (unit-экономика, бюджеты)
- `karina-hr` — Жулдыз, HR (подбор, онбординг)
- `karina-legal` — Виктор, юрист (договоры, оферты, РК)
- `karina-devops` — Максим, DevOps (деплой, домены, инфра)

## Конвейер «сайт под ключ»

CEO одобряет → PM планирует → (research + SEO параллельно) → копирайтер → UX-dev → QA → DevOps деплоит.
