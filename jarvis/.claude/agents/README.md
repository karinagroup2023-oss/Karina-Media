# Команда AI-субагентов KARINA Media

Субагенты Claude Code, сконвертированные из профилей `karina-hq/ai-team/`. Подхватываются автоматически при запуске Jarvis. Профили в `karina-hq/ai-team/` — источник истины (правишь роль → обновляй и профиль, и субагента).

## Конвейер «сайт под ключ»

CEO одобряет → PM планирует → (research + SEO параллельно) → копирайтер → UX-dev → QA → DevOps деплоит.

## Отдел маркетинга (3 слоя, контракты)

Полная схема, маппинг ролей из ТЗ на агентов и жёсткие контракты вход/выход (JSON) — `knowledge/marketing-org.md`. Оркестратор (Jarvis) делегирует по слоям и собирает структурированные выходы:

- **Слой 1 (фундамент):** Ренат (Audience_Insights + Positioning_Brand) → Мария (Funnel_Designer) → Тимур (Marketing_Analytics).
- **Слой 2 (каналы):** Content_SEO_Social = София + Николай; Performance_Ads (Самат) — спящий, ждёт бюджет.
- **Слой 3 (кросс-функции):** Лейла (Creative_Director) → Айгерим (Copy_Creator).
- **Редактор:** Marketing_Editor прогоняет любой выход по чек-листу до возврата. Продающие тексты дальше → cold-lead (голос ЦА).

Первый цикл (решение Еркина, 2026-06-23): активны Content_SEO_Social + Creative_Director + Marketing_Editor (органика, без рекламного бюджета). Email_CRM, Video, Visual_Brief, Product_Marketing, Marketing_Ops — отложены до отладки связок.

Менталитет аудитории по гео — `knowledge/audience-mentality.md`. Субагенты плоские: «подчинение» = зона ответственности и стандарт Марии, фактический вызов по конвейеру — через оркестратора (Jarvis).
