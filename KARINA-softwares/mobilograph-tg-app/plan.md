# Telegram Mini App — Мобилограф (Астана)

## Проект: Karina Media — Telegram Mini App для мобилографа

**Дата создания плана:** 24 марта 2026
**Локация:** Астана, Казахстан
**Целевая аудитория:** жители Астаны, 20-40 лет
**Язык интерфейса:** русский
**Модель оплаты:** Kaspi перевод (без интеграции, контактная информация)

---

## 1. MVP-функционал (первая версия)

### Обязательно в MVP

| # | Функция | Приоритет | Описание |
|---|---------|-----------|----------|
| 1 | Портфолио | P0 | Галерея работ с фильтрацией по категориям |
| 2 | Каталог услуг и тарифов | P0 | Список услуг с ценами и описанием |
| 3 | Бронирование съёмки | P0 | Выбор даты, времени и типа съёмки |
| 4 | Отзывы клиентов | P1 | Статичный список отзывов с именем, текстом и оценкой |
| 5 | Контакт с мобилографом | P0 | Кнопка «Написать в Telegram» + информация о Kaspi для оплаты |
| 6 | О мобилографе | P1 | Краткая информация, фото, описание опыта |

### Отложено на v2 (не входит в MVP)

- Онлайн-оплата через Kaspi API
- Личный кабинет клиента с историей заказов
- Push-уведомления о предстоящей съёмке
- Система промокодов и скидок
- Админ-панель для управления контентом
- Интеграция с Google Calendar
- Мультиязычность (казахский/английский)

## 3. Структура экранов

### 3.1. Главный экран (`/`)

**Назначение:** Первое впечатление, навигация по основным разделам.

**Элементы:**
- Шапка с фото и именем мобилографа
- Краткое описание: «Мобилограф в Астане — съёмка на iPhone»
- Баннер / слайдер с лучшими работами (3-5 фото)
- Навигационные карточки:
  - Портфолио
  - Услуги и цены
  - Забронировать съёмку
  - Отзывы
- Кнопка «Связаться» (Telegram MainButton)

---

### 3.2. Портфолио (`/portfolio`)

**Назначение:** Демонстрация работ для принятия решения клиентом.

**Элементы:**
- Фильтр по категориям (табы):
  - Все
  - Мероприятия
  - Love Story
  - Контент для Instagram
  - Предметная съёмка
  - Портретная съёмка
- Сетка фотографий (masonry grid или 2 колонки)
- По нажатию — полноэкранный просмотр с свайпом
- Подпись к фото (опционально)

**Данные:** `data/portfolio.json`
```json
[
  {
    "id": 1,
    "category": "love-story",
    "image": "/images/portfolio/ls-01.jpg",
    "thumbnail": "/images/portfolio/ls-01-thumb.jpg",
    "caption": "Love Story — Парк Президента"
  }
]
```

---

### 3.3. Услуги и тарифы (`/services`)

**Назначение:** Выбор типа съёмки и тарифа.

**Элементы:**
- Список услуг (карточки):
  - Название услуги
  - Краткое описание
  - Иконка / превью
  - Цена (от ... тг)
  - Кнопка «Подробнее»
- Экран деталей услуги (`/services/:id`):
  - Полное описание
  - Что входит (чек-лист)
  - Тарифы (Базовый / Стандарт / Премиум)
  - Примеры работ из портфолио
  - Кнопка «Забронировать эту съёмку»

**Услуги:**

| Услуга | Описание | Цена (от) |
|--------|----------|-----------|
| Мероприятия | Дни рождения, корпоративы, выпускные | 25 000 тг |
| Love Story | Парная съёмка для влюблённых | 20 000 тг |
| Контент для Instagram | Рилсы, сторис, фото для ленты | 15 000 тг |
| Предметная съёмка | Товары, еда, аксессуары | 10 000 тг |
| Портретная съёмка | Индивидуальная портретная фотосессия | 15 000 тг |

**Данные:** `data/services.json`

---

### 3.4. Бронирование (`/booking`)

**Назначение:** Оформление заявки на съёмку.

**Шаги (multi-step form):**

**Шаг 1 — Выбор услуги:**
- Если пришли с экрана услуги — предзаполнено
- Если нет — выбор из списка

**Шаг 2 — Выбор даты и времени:**
- Календарь (текущий и следующий месяц)
- Недоступные даты заблокированы (из JSON)
- Временные слоты: 09:00, 11:00, 13:00, 15:00, 17:00, 19:00

**Шаг 3 — Контактные данные:**
- Имя (предзаполнено из Telegram)
- Телефон (предзаполнено если доступно)
- Комментарий / пожелания (textarea)

**Шаг 4 — Подтверждение:**
- Сводка заказа: услуга, дата, время, имя
- Информация об оплате: «Оплата по Kaspi: +7 (7XX) XXX-XX-XX»
- Кнопка «Отправить заявку» (Telegram MainButton)

**После отправки:**
- Данные отправляются через Telegram Bot API мобилографу
- Клиент видит экран «Заявка отправлена! Мы свяжемся с вами в течение 1 часа»
- Haptic feedback через Telegram Web App API

**Данные:** `data/schedule.json` (занятые даты/слоты)

---

### 3.5. Отзывы (`/reviews`)

**Назначение:** Социальное доказательство качества услуг.

**Элементы:**
- Средняя оценка (звёзды) и количество отзывов
- Список отзывов:
  - Имя клиента
  - Оценка (1-5 звёзд)
  - Текст отзыва
  - Тип съёмки
  - Дата
- Фильтр по типу съёмки (опционально)

**Данные:** `data/reviews.json`

---

### 3.6. О мобилографе (`/about`)

**Назначение:** Доверие и личный бренд.

**Элементы:**
- Фото мобилографа
- Имя и краткая био
- Опыт работы, количество съёмок
- Оборудование (iPhone модель, аксессуары)
- Ссылки: Instagram, YouTube (через Telegram openLink)
- Контактная информация

---

### 3.7. Контакт (`/contact`)

**Назначение:** Быстрая связь с мобилографом.

**Элементы:**
- Кнопка «Написать в Telegram» (открывает чат с ботом/аккаунтом)
- Телефон для звонка
- Kaspi для оплаты: номер + QR-код
- Instagram аккаунт
- Локация: «Астана, выезд по всему городу»

## 5. Архитектура

### 5.1. Общая схема

```
[Клиент в Telegram]
        |
        v
[Telegram Web App (React SPA)]
        |
        |--- Читает данные из JSON-файлов (статика)
        |
        |--- При бронировании отправляет данные -->
        |
        v
[Telegram Bot API]
        |
        v
[Бот (Serverless Function)]
        |
        |--- Отправляет заявку мобилографу (Telegram-сообщение)
        |--- Отправляет подтверждение клиенту
```

### 5.4. Telegram Web App API — используемые методы

| Метод / Свойство | Где используется |
|------------------|------------------|
| `WebApp.ready()` | При загрузке приложения |
| `WebApp.expand()` | При загрузке — раскрыть на весь экран |
| `WebApp.MainButton` | Кнопка «Забронировать» / «Отправить заявку» |
| `WebApp.BackButton` | Навигация назад между экранами |
| `WebApp.HapticFeedback` | При успешной отправке заявки |
| `WebApp.themeParams` | Адаптация цветов под тему Telegram |
| `WebApp.initDataUnsafe.user` | Предзаполнение имени клиента |
| `WebApp.openLink()` | Открытие Instagram, YouTube |
| `WebApp.openTelegramLink()` | Открытие чата с мобилографом |
| `WebApp.sendData()` | Отправка данных бронирования боту |
| `WebApp.close()` | Закрытие после успешной заявки |

### 5.5. Telegram-бот (минимальная логика)

```
Клиент нажимает «Отправить заявку»
        |
        v
WebApp.sendData(JSON) --> Telegram передаёт боту event `web_app_data`
        |
        v
Бот парсит данные заявки
        |
        v
Бот отправляет мобилографу сообщение:
  "Новая заявка!
   Услуга: Love Story
   Дата: 5 апреля 2026, 15:00
   Клиент: Айбек (@aibek)
   Телефон: +7 701 123 4567
   Комментарий: Хотим съёмку в парке"
        |
        v
Бот отвечает клиенту: "Заявка принята! Мы свяжемся с вами в ближайшее время."
```

## 7. Метрики успеха MVP

- Количество открытий Mini App в неделю
- Количество заявок на бронирование через приложение
- Конверсия: открытие -> заявка (цель: > 10%)
- Среднее время от заявки до подтверждения (цель: < 1 часа)
- Количество повторных клиентов через приложение
